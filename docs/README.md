# Chess Analyzer

## Project Goal
The goal of this project is to develop a Java-based chess analyzer that evaluates chess positions and recommends the best possible move(s) using search algorithms.

## MVP
- Set up the Java project and create a basic chessboard using a 2D array.
- Implement all chess pieces and their legal movement rules.
- Add turn tracking, capturing, and check/checkmate detection.
- Create a way to input or load a chess position using FEN notation.
- Implement a board evaluation function that assigns values to pieces and estimates positional advantages.
- Implement the Minimax algorithm to search possible moves up to 3 plies ahead.
- Improve search efficiency and allow deeper analysis.
- Display the best recommended move and its evaluation score.
